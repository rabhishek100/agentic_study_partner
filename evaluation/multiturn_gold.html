mt-001-t4: How does reservoir sampling work?

Route
retrieval_qa
History
independent
Standalone query
How does reservoir sampling work?
Scope
global

Reference answer

Keep the first k stream items in a reservoir. For the nth incoming item, draw i uniformly from 1 through n; if i is at most k, replace reservoir item i, otherwise discard the new item [N59:P106]. This gives each observed item probability k/n of being in the reservoir, so the process can stop at any time with a uniform sample [N60:P107].

mt-002-t3: How does the streaming one maintain a fair sample?

History
dependent
Standalone query
How does reservoir sampling maintain a uniform sample from an unknown-length stream?
Scope
{'kind': 'section', 'node_id': 54}

Reference answer

Reservoir sampling fills k slots with the first k items. For item n it draws i uniformly from 1..n and replaces reservoir slot i only when i ≤ k [N59:P106]. Consequently, both the incoming item and retained items have probability k/n of being present, preserving a uniform sample at every stopping point [N60:P107].

Compare reservoir sampling with importance sampling.
Scope

Reference answer

Reservoir sampling selects a fixed-size uniform sample from a stream whose total length is unknown [N59:P106]. Importance sampling addresses a different problem: when target distribution P is expensive or infeasible to sample, draw from proposal Q and weight samples by P(x)/Q(x), provided Q is positive wherever P is nonzero [N60:P107].

Reference answer

Online prediction generates a response when a request arrives and is optimized for low latency; batch prediction generates predictions periodically, stores them, and is optimized for throughput [N106:P217] [N106:P220]. Separate batch and streaming feature pipelines can diverge [N108:P224], motivating unified processing or feature-store infrastructure [N108:P225].
